# FurEver Care - Asset Credits

## Local website images
All `<img>` content used by the website is stored locally in `assets/images/`, so the main visual content does not depend on remote image URLs.

The local pet/product photographs and illustrations in this revision were extracted/cropped from the supplied **PetCare Website Design and Development - SRS** PDF for this project demonstration. No AI-generated image assets were added in this revision.

## Icons
UI emoji glyphs were replaced with locally bundled **Bootstrap Icons** (`vendor/bootstrap-icons.min.css`).

## External embeds
The Grooming Videos section still uses a YouTube privacy-enhanced embed, and Contact/Shelter sections use Google Maps embeds. These are embeds rather than website image assets and require internet access when viewed.
