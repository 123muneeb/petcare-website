FurEver Care - Project ReadMe
============================

1. Open this folder in VS Code.
2. Run with Live Server, OR run: python -m http.server 8000
3. Open: http://localhost:8000

Assumptions:
- Front-end only; no server-side storage.
- Product Buy Now buttons do not purchase anything.
- Appointment slots are display-only.
- Feedback is UI-only.
- Demo contact details are fictional/static.
- JSON, TXT and XML files must be served over HTTP for browser AJAX/fetch access.
- External images/maps/video require an internet connection.

See README.md and PROJECT_REPORT.md for full details.
